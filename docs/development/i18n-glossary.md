# Bengali (বাংলা) UI glossary & style

Use these terms everywhere so the app speaks with one voice. Add new terms here.

## Style
- Address the user politely and directly (**আপনি** form). Buttons and commands use the polite
  imperative: *সংরক্ষণ করুন*, *যোগ করুন*, *মুছে ফেলুন*.
- Short and natural; no word-for-word English structure. Prefer the common spoken term over a
  Sanskritised one (*ফোন* not *দূরভাষ*).
- **Do not translate:** the brand **AltCare**, user-entered data (names, addresses, notes),
  medicine names and potencies (Arnica 30C), codes/IDs, email addresses, URLs, units like *mg*/*ml*
  and *km*. The currency symbol is **৳** (BDT).
- Numbers stay ASCII digits (1, 2, 3) in the UI; dates use `useDateFormat()` (Bengali numerals).
- Keep ICU placeholders exactly: `{count}`, `{name}`. Plurals: Bengali has no plural form, so
  one string is enough.
