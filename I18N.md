## Overview

AltCare is a **bilingual platform** designed for the Bangladesh market. Every user-facing string, error message, notification, and medical content is available in both English and Bengali.

### Why Bilingual?

**Market adoption:**
- 98% of Bangladesh population speaks Bengali natively
- Many practitioners prefer Bengali interface
- Patients expect Bengali medicine names
- Regulatory documents often in Bengali

**Implementation approach:**
- Default language: English (en)
- Secondary language: Bengali (bn)
- User-selectable preference (stored in database)
- Fallback to English if Bengali translation missing

## Backend Implementation

### Technology Stack

**Library:** Babel (Python i18n)

```python
# app/core/i18n.py
from babel import Locale
from babel.support import Translations
import gettext

class I18nManager:
    def __init__(self):
        self.translations = {
            'en': gettext.translation('messages', 'locales', languages=['en']),
            'bn': gettext.translation('messages', 'locales', languages=['bn']),
        }
        self.default_locale = 'en'
    
    def get_text(self, key: str, locale: str = 'en') -> str:
        """Get translated text for a key"""
        trans = self.translations.get(locale, self.translations['en'])
        return trans.gettext(key)
    
    def ngettext(self, singular: str, plural: str, n: int, locale: str = 'en') -> str:
        """Get pluralized translation"""
        trans = self.translations.get(locale, self.translations['en'])
        return trans.ngettext(singular, plural, n)

i18n = I18nManager()
```

### Middleware

```python
# app/middleware/language.py
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware

class LanguageMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        # Get language from Accept-Language header or user preference
        lang = request.headers.get('Accept-Language', 'en')[:2]
        
        # Validate language (only en/bn supported)
        if lang not in ['en', 'bn']:
            lang = 'en'
        
        # Store in request state
        request.state.language = lang
        
        response = await call_next(request)
        response.headers['Content-Language'] = lang
        return response
```

### API Responses

All API responses include localized messages:

```python

@router.post("/patients")
async def create_patient(
    patient: PatientCreate,
    request: Request,
    db: AsyncSession = Depends(get_db),
):
    lang = request.state.language
    
    try:
        # Create patient...
        return {
            "data": patient_data,
            "message": i18n.get_text("patient.created_success", lang)
            # English: "Patient created successfully"
            # Bengali: "রোগী সফলভাবে তৈরি হয়েছে"

        raise HTTPException(
            status_code=400,
            detail=i18n.get_text("patient.create_error", lang)
        )
```

### Language Switcher

```tsx
// components/LanguageSwitcher.tsx
'use client';
import {useLocale} from 'next-intl';
import {useRouter, usePathname} from 'next/navigation';

export default function LanguageSwitcher() {
  const locale = useLocale();
  const router = useRouter();
  const pathname = usePathname();
  
  const switchLanguage = (newLocale: 'en' | 'bn') => {
    // Update user preference in backend
    fetch('/api/v1/users/me/language', {
      method: 'PATCH',
      body: JSON.stringify({ language: newLocale })
    });
    
    // Navigate to new locale
    const newPath = pathname.replace(`/${locale}`, `/${newLocale}`);
    router.push(newPath);
  };
  
  return (
    <div className="flex gap-2">
      <button
        onClick={() => switchLanguage('en')}
        className={locale === 'en' ? 'active' : ''}
      >
        English
      </button>
      <button
        onClick={() => switchLanguage('bn')}
        className={locale === 'bn' ? 'active' : ''}
      >
        বাংলা
      </button>
    </div>
  );
}
```

### Translations Table

```sql
CREATE TABLE translations (
  id UUID PRIMARY KEY,
  translation_key VARCHAR(255) NOT NULL UNIQUE,
  text_en TEXT NOT NULL,
  text_bn TEXT NOT NULL,
  category VARCHAR(100),  -- 'ui', 'error', 'email', etc.
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## Translation Workflow

### 1. Adding New Keys

**When adding new UI text:**

1. Add to English messages file:
```json
// messages/en.json
{
  "feature": {
    "new_button": "Click Me"
  }
}
```

2. Add to Bengali messages file:
```json
// messages/bn.json
{
  "feature": {
    "new_button": "আমাকে ক্লিক করুন"
  }
}
```

3. Update database translations table:
```sql
INSERT INTO translations (translation_key, text_en, text_bn, category)
VALUES ('feature.new_button', 'Click Me', 'আমাকে ক্লিক করুন', 'ui');
```

### 2. Bulk Translation

**For large batches:**

1. Export untranslated keys:
```bash
python scripts/export_untranslated.py > untranslated.csv
```

2. Send to translation service or Bengali speaker

3. Import translations:
```bash
python scripts/import_translations.py translated.csv
```

### 3. Quality Assurance

**Translation review checklist:**
- [ ] Culturally appropriate
- [ ] Grammatically correct Bengali
- [ ] No Banglish (Bengali written in English letters)
- [ ] Consistent terminology
- [ ] Proper use of Bengali script
- [ ] Respectful tone for medical context

## Content Guidelines

### Medical Terms

**Preference:** Use Bengali terms where commonly understood, keep English in parentheses if needed.

**Examples:**
- Prescription → প্রেসক্রিপশন
- Medicine → ওষুধ
- Patient → রোগী
- Doctor → ডাক্তার
- Diagnosis → রোগ নির্ণয়
- Symptom → লক্ষণ
- Dosage → ডোজ (or ডোসেজ)

### Medicine Names

**Traditional medicines:** Use Bengali names primarily
- আর্নিকা মন্টানা (Arnica Montana)
- নাক্স ভমিকা (Nux Vomica)
- ব্রায়োনিয়া (Bryonia)

**Modern medicines:** Keep English names, add Bengali if common
- Paracetamol (প্যারাসিটামল)
- Ibuprofen

### Numbers and Dates

**Bengali numerals (optional):**
- 0-9 → ০-৯
- Generally use Western numerals (0-9) for better readability

**Dates:**
- English: "April 21, 2026"
- Bengali: "২১ এপ্রিল, ২০২৬"

### Formality

**Use formal Bengali (আপনি) for:**
- Patient-facing content
- Official communications
- Error messages
- System notifications

**Example:**
- "আপনার অ্যাকাউন্ট তৈরি হয়েছে" (Your account has been created)
- NOT: "তোমার অ্যাকাউন্ট..." (informal)

## Testing i18n

### Manual Testing

**Test checklist:**
- [ ] Switch language from English → Bengali
- [ ] Switch language from Bengali → English
- [ ] All navigation labels translated
- [ ] Form labels and placeholders translated
- [ ] Error messages in correct language
- [ ] Success notifications in correct language
- [ ] Email templates use user's language
- [ ] PDF prescriptions show Bengali names
- [ ] Medicine search works in both languages
- [ ] Date/number formatting correct

### Automated Tests

```typescript
// tests/i18n.test.ts
import {describe, it, expect} from 'vitest';
import enMessages from '../messages/en.json';
import bnMessages from '../messages/bn.json';

describe('i18n completeness', () => {
  it('should have all keys in both languages', () => {
    const enKeys = flattenKeys(enMessages);
    const bnKeys = flattenKeys(bnMessages);
    
    expect(enKeys).toEqual(bnKeys);
  });
  
  it('should have no empty translations', () => {
    const bnValues = Object.values(flattenObject(bnMessages));
    
    bnValues.forEach(value => {
      expect(value).not.toBe('');
      expect(value).not.toBe(undefined);
    });
  });
});
```

## Performance Optimization

### Caching

**Backend: Cache translations in Redis**
```python
# Load translations on startup, cache for 1 hour
@app.on_event("startup")
async def load_translations():
    translations = await db.execute(select(Translation))
    cache_data = {t.key: {'en': t.text_en, 'bn': t.text_bn} for t in translations}
    await redis.set('translations', json.dumps(cache_data), ex=3600)
```

**Code splitting by language:**
```typescript
// Only load active language messages
const messages = await import(`./messages/${locale}.json`);
```
